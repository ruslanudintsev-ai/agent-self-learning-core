# Протокол самосовершенствования (Continuous Skill Evolution)

Этот скилл регулирует процесс постоянного самообучения, рефлексии и расширения возможностей агента в проекте.

В автономных средах агент не рассуждает «в фоне» без вызова. Поэтому самообучение встроено прямо в жизненный цикл выполнения каждой задачи:

```
[Поступила задача]
       │
       ▼
[Выполнение через python manage.py / core]
       │
       ├─► Успех? ──► [Post-Run Reflection] ──► Запись в рецепты / cheat-sheet
       │
       └─► Ошибка или нехватка функции?
                 │
                 ▼
       [Расширение core/commands/ или фиксация gotchas.md] ──► Запись в changelog / backlog
```

## Правила рефлексии по результатам работы

1. **Новый практический кейс (Рецепт):**
   - Если для решения задачи потребовалась интересная комбинация флагов или параметров `manage.py`, добавь готовый рецепт в `.agents/skills/agent-cli/SKILL.md` (секция «Рецепты вызовов»).

2. **Ошибки и краевые случаи (Gotchas & Memory):**
   - Если команда упала из-за таймаута, специфики ОС, блокировки процессов или ошибки аргументов:
     - Запиши точный кейс и способ его обхода в `.agents/skills/agent-cli/gotchas.md`.
     - Проверь, чтобы формулировка была однозначной и предотвращала повторение ошибки.

3. **Недостающий функционал CLI (Feature Generation):**
   - **Вместо мусорных одноразовых скриптов:** Никогда не оставляй в корне проекта временные скрипты вида `temp_check.py` или `fix.py`.
   - Если операция полезна и может понадобиться снова:
     1. Создай изолированный модуль: `cle dev-scaffold --command <name>`.
     2. Реализуй методы `configure_parser(parser)` и `run(args)`.
     3. Проверь код через `cle dev-validate --file core/commands/<name>.py --json`.
     4. Напиши тест в `tests/`.
     5. Актуализируй документацию через `cle system-docgen`.
   - Если добавление команды отложено:
     - Зафиксируй тикет в `.agents/backlog/cli-features.md`.

4. **Журналирование эволюции (Changelog):**
   - При добавлении новой команды или значимого рецепта сделай отметку в `.agents/skills/agent-cli/changelog.md` с датой и кратким описанием.
