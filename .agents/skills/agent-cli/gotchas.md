# Память граблей агента (Gotchas & Workarounds)

Обращайся к этому справочнику точечно при возникновении ошибок или специфики операционной системы и библиотек.

---

### Gotcha 1: Блокировка интерактивного stdin в фоновых процессах Windows
* **Симптом:** CLI-команды или внешние утилиты (OpenCode, Node, Python) зависают без завершения и без логов при запуске в фоне.
* **Первопричина:** На платформе Windows/PowerShell процесс ожидает интерактивного потока ввода (TTY stdin).
* **Решение / Правило:** Всегда перенаправлять пустой ввод:
  ```powershell
  $null | python manage.py <command>
  # или через cmd:
  cmd.exe /c "python manage.py <command> < nul"
  ```

---

### Gotcha 2: Блокировка системных баз данных SQLite открытыми процессами
* **Симптом:** `sqlite3.OperationalError: database is locked`.
* **Первопричина:** Файл базы данных занят эксклюзивной блокировкой работающим процессом (например, браузером или демоном).
* **Решение / Правило:** Никогда не подключаться напрямую к активному файлу SQLite. Всегда копировать файл во временную директорию перед чтением (`shutil.copy2`), читать копию и удалять ее после завершения.

---

### Gotcha 3: Защита контекстного окна LLM от раздувания (Output Budgeting)
* **Симптом:** Переполнение контекста модели и деградация рассуждений при случайном выводе сырых дампов (тысячи строк логов).
* **Первопричина:** Отсутствие лимита символов в стандартном выводе CLI-команд.
* **Решение / Правило:** Все команды наследуются от `BaseCommand`, в который аппаратно вшит `OutputBudget` (максимум 12 000 символов) с автоматическим обрезанием и пометкой `[TRUNCATED ... chars by Output Budget. Use specific query/slice]`.

---

### Gotcha 4: Разграничение сред (Target Host Guard)
* **Симптом:** Агент пытается запустить боевой сервер или деструктивную операцию на локальной Dev-машине.
* **Первопричина:** Отсутствие программной защиты от выполнения боевых сценариев на машине разработчика.
* **Решение / Правило:** Метод `assert_production_host()` в `BaseCommand` проверяет окружение и мгновенно прерывает выполнение с ошибкой `ENVIRONMENT_BOUNDARY_VIOLATION`, требуя запуска только с флагом `--dry-run` на локальном ПК.
