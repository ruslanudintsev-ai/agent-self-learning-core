# Справочник команд Command Layer Engine (CLE)

> Данный файл сгенерирован автоматически через `cle system-docgen`. Не редактируйте вручную.

## Доступные команды

### `cle dev-scaffold`
**Назначение:** Автоматическая генерация готовых pytest-тестов для команд из core/commands/

| Аргумент | Обязательный | Описание | По умолчанию |
| :--- | :---: | :--- | :--- |
| `--command` | Да | Имя команды для генерации теста (например: service-health) | - |
| `--output-dir` | Нет | Директория для сохранения тестового файла | `C:\Users\user\Documents\agent-self-learning-core\tests` |
| `--dry-run` | Нет | Режим симуляции: показать код теста без записи на диск | `False` |

### `cle dev-validate`
**Назначение:** Pre-commit валидация модулей core/commands/ на соответствие регламенту

| Аргумент | Обязательный | Описание | По умолчанию |
| :--- | :---: | :--- | :--- |
| `--file` | Да | Путь к валидируемому файлу команды (например core/commands/my_cmd.py) | - |
| `--dry-run` | Нет | Режим симуляции проверки без тестового запуска подпроцесса | `False` |

**Назначение:** Автогенерация SKILL.md (алиас для system-docgen)

| Аргумент | Обязательный | Описание | По умолчанию |
| :--- | :---: | :--- | :--- |

| `--dry-run` | Нет | Вывести сгенерированный Markdown в stdout без перезаписи файла | `False` |

### `cle exec`
**Назначение:** Выполнение Python-выражения или скрипта в контексте проекта без создания временных файлов

| Аргумент | Обязательный | Описание | По умолчанию |
| :--- | :---: | :--- | :--- |
| `--code` | Да | Python-код или выражение для выполнения | - |
| `--timeout` | Нет | Таймаут выполнения в секундах (по умолчанию 15) | `15` |
| `--dry-run` | Нет | Проверить синтаксис кода без фактического выполнения | `False` |

## Общие системные флаги
- `--json`: Обязательный флаг при вызове агентом для получения структурированного JSON ответа.
- `--dry-run`: Симуляция выполнения для команд с деструктивными операциями.

## Рецепты вызовов
1. **Создание новой команды (Dev Scaffold):**
   ```bash
   cle dev-scaffold --command cache-cleaner
   ```
2. **Проверка качества и AST валидация:**
   ```bash
   cle dev-validate --file core/commands/cache_cleaner.py --json
   ```
3. **Актуализация документации скила на лету:**
   ```bash
   cle system-docgen
   ```
4. **Безопасные ad-hoc вычисления без создания файлов (Zero-Context Interpreter):**
   ```bash
   cle exec --code "2 + 2" --json
   cle exec --code "import os; result = os.listdir('.')" --json
   ```
5. **Управление снимками конфигураций и откат:**
   ```bash
   cle rollback create --reason "before_update" --json
   cle rollback list --json
   cle rollback restore --last --dry-run --json
   cle rollback restore --last --json
   ```
6. **Диагностика системы и процессов:**
   ```bash
   cle sys-info --json
   cle service-health --json
   ```
