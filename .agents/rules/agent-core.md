# ДНК Агента: Законы взаимодействия

1. **Единая точка входа (Zero Ad-Hoc Scripts):**
   - Все операции с инфраструктурой, базами данных, сетью, файлами и расчетами выполняются ТОЛЬКО через `cle` (`python manage.py <command>`).
   - Создание временных скриптов (`temp_*.py`, `test.py`, `check.py` в корне проекта или `/tmp`) **СТРОГО ЗАПРЕЩЕНО**. Для вычислений на лету используй `cle exec --code "..."`.

2. **Экономия контекста (Доверяй CLI):**
   - Если штатная команда `cle <cmd> --json` вернула результат, **СТРОГО ЗАПРЕЩЕНО** открывать и перечитывать исходный код `.py` файлов реализации в `core/commands/`.
   - Формула эффективного ответа: **Один вопрос = один вызов CLI**. Не жги лимиты пользователя на избыточное чтение кодовой базы.

3. **Точечная память граблей (Gotchas on Demand):**
   - Обращайся к `.agents/skills/agent-cli/gotchas.md` точечно при возникновении ошибок или специфики ОС/библиотек. Не перечитывай весь файл целиком без необходимости.

4. **Изоляция сред (Environment Boundary):**
   - Локальный ПК — исключительно Dev-среда (написание кода, оффлайн-тесты, `--dry-run`).
   - Боевой запуск разрешен ТОЛЬКО на авторизованных Production-нодах. На машине разработчика потенциально деструктивные действия блокируются Target Host Guard.
