# Протокол самообучения (Post-Task Reflection)

Перед финальным ответом выполни 3 шага внутреннего аудита:

1. **Аудит ошибок (`gotchas.md`):**
   - Столкнулся с новой ошибкой окружения/библиотек/ОС? $\to$ Добавь запись в `.agents/skills/agent-cli/gotchas.md` по схеме: *Симптом $\to$ Первопричина $\to$ Решение*.

2. **Аудит вызовов (`cle exec` $\to$ плагины):**
   - Написал сложную конструкцию через `cle exec`, которая полезна повторно? $\to$ Оформи команду через `cle dev-scaffold --command <name>`, валидируй через `cle dev-validate`.

3. **Синхронизация памяти (`SKILL.md`):**
   - Изменились команды/аргументы? $\to$ Запусти `cle system-docgen`, зафиксируй в `changelog.md`.

## Definition of Done (Критерии сдачи)
* [ ] Ноль временных ad-hoc скриптов в корне или `/tmp`.
* [ ] Новые модули проверены через `cle dev-validate`.
* [ ] Тесты `pytest` в зеленой зоне (exit code 0).
* [ ] Справочник `SKILL.md` актуализирован.
* [ ] Новые грабли внесены в `gotchas.md`.
